SPRING2 for Windows

This installer places SPRING2 under Program Files\SPRING2 and installs the
main command-line executable as spring2.exe.

Usage notes:
- The installer can optionally add the install directory to the system PATH.
  Enable the "Add SPRING2 to the system PATH" task during setup if you want to
  launch `spring2` from any new PowerShell or Command Prompt session.
- The installer creates a Start Menu shortcut to `spring2.exe` and can also add
  an optional desktop shortcut if you enable that task during setup.
- Run SPRING2 from PowerShell or Command Prompt using the full install path, or
  add the install directory to PATH if you want `spring2` available globally.
- GitHub releases also publish a portable spring2.exe if you prefer to keep the
  binary in a custom tools directory instead of using the installer.
